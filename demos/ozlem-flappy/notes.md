# Özlem Flappy Test — Proje Notları ve Mimari

## Mimari Özeti
- **Motor:** Saf JavaScript + HTML5 Canvas (`requestAnimationFrame`).
- **Assetler:** WebP formatında paged atlaslar ve parçalanmış JSON frame tanımları.
- **Ses:** YouTube iframe API (skor 10+ bonus) ve dahili Web Audio API sentezleyici (SFX).
- **Fizik:** Basit yerçekimi, zıplama ivmesi, heykel alpha silueti çarpışma kontrolü.
